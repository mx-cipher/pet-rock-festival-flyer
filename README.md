# Build an Event Flyer Page

This is a clean and simple event flyer webpage for the **Pet Rock Festival**. Built as part of the **freeCodeCamp** Responsive Web Design certification layout curriculum.

## Concepts Applied
- **Semantic HTML:** Structuring headers, main sections, lists, and footers.
- **Basic Typography:** Formatting fonts using `rem` units for accessible scaling.
- **Relative Spacing:** Utilizing `em` units for proportional list-item margins.
- **Dynamic Math:** Implementing CSS `calc()` to measure consistent layout height.

## Project Scope
Styled completely using beginner-friendly Core CSS concepts (Colors, Borders, Margins, Paddings, and Text Alignment) without using advanced CSS frameworks or layouts.
